eMudhra is a certificate authority: its job is proving a website is who it says it is, and it says it has issued over 60 million certificates. Meaning

A memory mix-up inside PHP hands a stranger the server

PHP reuses the same worker for request after request. Both bugs are about clean-up: when a request fails in an unusual way, PHP can leave behind scraps of memory it still trusts. A later request can pick them up. An attacker who arranges this can run their own commands on the server with the same rights as the website.

No password or account is needed, and the website's own code does not have to be faulty. A fully updated WordPress on an old PHP is still exposed.

CVE-2026-109618

Out-of-memory clean-up

9.2of 10, PHP's rating

PHP's title: RCE via OOM corruption. When a request runs out of memory, PHP can treat half-built data as valid while cleaning up.

CVE-2026-109619

Leftovers between requests

9.2of 10, PHP's rating

PHP's title: RCE via stale global state. Data from one request can outlive its memory and be used by the next request on the same worker.

RCE: remote code execution, running commands on someone else's computer. watchTowr rated the bugs 10.0. Sansec reports one path can also leak memory from other visitors' requests, such as passwords and session tokens.

Timeline

Fourteen years hidden, ten weeks to fix, attacks four days before the patch

The weakness was noticed more than once and left alone because nobody showed it could be used. In 2026 researchers working with AI models showed it could. Wiz credits frontier AI models with lowering the cost of turning the bug into an attack.

      How it was found

      At least three teams found the bug independently in August 2026, each working with AI models. The PHP Foundation says one of its developers saw first signs of the same out-of-memory problem in a 2024 audit, and the fix stalled for months; it calls that a structural failure of its own decision process.

      PHP's security inbox since 1 July

      Reports to the PHP security team, per the PHP Foundation (21 Oct). It says AI-assisted research has raised the volume sharply.

      The embargo argument

      The PHP Foundation says Chainguard broke the embargo and handed attackers the fix in binary form. Chainguard's CEO says vendors were reporting attacks and the bug was easy to rediscover. Commenters on Hacker News split on whether coordinated disclosure still works when a vague hint is enough to find a bug again.

      Who pays for PHP's security

      A small team funded by the PHP Foundation, plus volunteers. The 2024 audit was paid for by Germany's Sovereign Tech Agency; the Ecosystem Security Team by Alpha-Omega. The Foundation has asked hosts, cloud providers and governments to fund more.

      Compared

      Researchers compare PHP2Shell most often with Heartbleed, for the memory leak (Wiz, Sansec), and with Log4Shell, for a buried component that every company first has to find in its own systems. The earlier PHP flaw closest in kind, CVE-2024-4577, was exploited within a day and used by ransomware; its exposed count fell 96% in nine months. Heartbleed still had about 91,000 exposed servers five years after its fix.

      Trends

      1. AI shortened the clock. Three teams found the bug within weeks of each other, all with AI help, and the PHP Foundation reports more AI-assisted reports than its small team can easily handle. OpenAI and Chainguard both expect more like this.
      2. Embargoes leak sooner. The bug numbers leaked 23 hours before the planned release, PHP moved the release forward a day, and one vendor shipped six hours early anyway.
      3. "Take it offline" became the stopgap. Agencies in the US, UK and the Netherlands advised it before any confirmed break-in, and governments from Czechia to Denmark complied on their own sites.
      4. The long tail is end-of-life PHP. About 1.1 million exposed hosts run branches PHP no longer releases fixes for (VulnCheck). Past bugs suggest a fast first drop and then a residue that lasts for years.
      5. Markets read it as demand for defenders. Cloudflare rose about 5.5% and CrowdStrike about 5.3% intraday on 21 October (Investing.com).
      6. Asia was loudest in Japan. The Prime Minister addressed it, hosts went into emergency maintenance, and a public tally counted 211 organisations. Singapore and Australia issued alerts. As of the evening of 21 October, ThaiCERT had published no notice that this page could find.

      Fix

      Update PHP, restart every PHP process, then check

      A running PHP process keeps the old code in memory until it restarts. An update without a restart leaves the hole open.
